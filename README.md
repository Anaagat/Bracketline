Bracketline
A desktop tournament tracker for macOS and Windows.
- Create random draws or arrange brackets manually.
- Explore a mirrored tournament graph with panning and zooming.
- Click an entrant to record a win and advance them automatically.
- Import up to 256 names per batch, with no fixed total entrant cap.
- Import and export tournament JSON files.
- Customize themes, colors, and backgrounds with Imprint-compatible settings.
Tournament progress saves locally on your device.
